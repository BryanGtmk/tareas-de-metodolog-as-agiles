\subsubsection{Fundamento de TDD}

El desarrollo guiado por pruebas, conocido como TDD, es una práctica de desarrollo de software en la que primero se define una prueba automatizada y posteriormente se implementa el código necesario para que dicha prueba sea superada. Esta práctica se relaciona con las metodologías ágiles porque favorece la entrega incremental, la retroalimentación temprana y la mejora continua del código \cite{beck2003tdd,agilepracticeguide2017}.

El ciclo TDD se compone de tres fases principales:

\begin{itemize}
    \item \textbf{Red:} se escribe una prueba que falla porque la funcionalidad aún no existe o no cumple el comportamiento esperado.
    \item \textbf{Green:} se implementa el código mínimo necesario para que la prueba pase.
    \item \textbf{Refactor:} se mejora la estructura interna del código sin alterar el resultado esperado.
\end{itemize}

La práctica desarrollada aplicó este ciclo sobre el proyecto \texttt{TStudent.Core} y el proyecto de pruebas \texttt{TStudent.Tests}. La solución fue construida de forma progresiva, validando cada cálculo estadístico mediante pruebas unitarias con xUnit \cite{xunit2026docs}.

\subsubsection{Fórmulas estadísticas utilizadas}

El cálculo del estadístico T-Student se desarrolló a partir de conceptos estadísticos básicos. La prueba t se fundamenta en la comparación entre una media muestral y una media hipotética \cite{student1908probable}.

\begin{equation}
\bar{x} = \frac{\sum x_i}{n}
\end{equation}

\begin{equation}
s^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1}
\end{equation}

\begin{equation}
s = \sqrt{s^2}
\end{equation}

\begin{equation}
t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}
\end{equation}

Donde:

\begin{itemize}
    \item $x_i$: cada dato de la muestra.
    \item $n$: cantidad de datos.
    \item $\bar{x}$: media muestral.
    \item $s^2$: varianza muestral.
    \item $s$: desviación estándar muestral.
    \item $\mu_0$: media hipotética.
    \item $t$: estadístico T-Student.
\end{itemize}

\subsubsection{\texttt{TStudentCalculator.cs}}

\begin{lstlisting}[language=CSharp, caption={Código final de la clase TStudentCalculator}]
namespace TStudent.Core;

public class TStudentCalculator
{
    public double CalcularMedia(double[] muestra)
    {
        ValidarMuestraConDatos(muestra);

        return CalcularSuma(muestra) / muestra.Length;
    }

    public double CalcularVarianzaMuestral(double[] muestra)
    {
        ValidarMuestraParaVarianza(muestra);

        double media = CalcularMedia(muestra);

        return CalcularSumaDiferenciasCuadradas(muestra, media) / (muestra.Length - 1);
    }

    public double CalcularDesviacionEstandarMuestral(double[] muestra)
    {
        double varianza = CalcularVarianzaMuestral(muestra);

        return Math.Sqrt(varianza);
    }

    public double CalcularTStudent(double[] muestra, double mediaHipotetica)
    {
        double media = CalcularMedia(muestra);
        double desviacion = CalcularDesviacionEstandarMuestral(muestra);
        double errorEstandar = desviacion / Math.Sqrt(muestra.Length);

        return (media - mediaHipotetica) / errorEstandar;
    }

    private static void ValidarMuestraConDatos(double[] muestra)
    {
        if (muestra is null)
        {
            throw new ArgumentNullException(nameof(muestra));
        }

        if (muestra.Length == 0)
        {
            throw new ArgumentException("La muestra no puede estar vacia.", nameof(muestra));
        }
    }

    private static void ValidarMuestraParaVarianza(double[] muestra)
    {
        ValidarMuestraConDatos(muestra);

        if (muestra.Length < 2)
        {
            throw new ArgumentException("La muestra debe tener al menos dos datos.", nameof(muestra));
        }
    }

    private static double CalcularSuma(double[] muestra)
    {
        double suma = 0;

        foreach (double valor in muestra)
        {
            suma += valor;
        }

        return suma;
    }

    private static double CalcularSumaDiferenciasCuadradas(double[] muestra, double media)
    {
        double suma = 0;

        foreach (double valor in muestra)
        {
            double diferencia = valor - media;
            suma += diferencia * diferencia;
        }

        return suma;
    }
}
